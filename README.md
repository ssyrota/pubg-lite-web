# Stormline Royale

An original browser battle royale (Three.js), playable on desktop. Solo vs bots, squads of up to 3, and online play without a server.

- **Play:** open `dist/stormline-royale.html` in Chrome or Firefox. For online play, both players open it; one hosts, the other joins with the room code.
- **Build:** `python3 build.py` (src/ → dist/)
