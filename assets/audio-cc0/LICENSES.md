# Audio licenses

All files in this folder are CC0 1.0 (public domain dedication), made by Kenney (kenney.nl).
Each pack's README states: "Assets included in this package (2D sprites, 3D models and sound effects) are CC0 licensed".

| folder | source repo | files |
|---|---|---|
| kenney_cc0 | github.com/KenneyNL/Starter-Kit-FPS (sounds/) | walking, jump_a/b/c, land, weapon_change, blaster*, enemy_* |
| kenney_platformer | github.com/KenneyNL/Starter-Kit-3D-Platformer | walking, jump, land, fall, break, coin |
| kenney_racing | github.com/KenneyNL/Starter-Kit-Racing | engine, impact, skid (skid by Landeplage, also CC0) |
| kenney_city | github.com/KenneyNL/Starter-Kit-City-Builder | ambience |

None of these are embedded in the game yet (task: Audio). Realistic firearm recordings were not reachable from
the build sandbox; the best CC0 option is "The Free Firearm Sound Library"
(https://opengameart.org/content/the-free-firearm-sound-library, CC0).
